# NextGen Health Rx Checkout

Checkout for **NextGen Health Rx**. Shoppers choose a treatment, enter contact and shipping details, apply a coupon when one is offered, pay, and reach the order confirmation page.

The repository name is `nextgenhealthrxcheckout` because this project is the checkout code for NextGen Health Rx.

## Stack

- React
- Create React App
- React Router
- Axios
- Tailwind CSS
- styled-components
- React Hot Toast

## Requirements

- Node.js 18 or later
- npm

## Run locally

```bash
git clone https://github.com/shiv-dev-01/nextgenhealthrxcheckout.git
cd nextgenhealthrxcheckout
cd nextgenhealthrx_checkout_1\nextgenhealthrx_checkout_1
npm install
npm start
```

The dev server opens at http://localhost:3000.

## Scripts

| Command | What it runs |
| --- | --- |
| `npm run start` | `react-scripts start` |
| `npm run build` | `react-scripts build` |
| `npm run test` | `react-scripts test` |
| `npm run eject` | `react-scripts eject` |
